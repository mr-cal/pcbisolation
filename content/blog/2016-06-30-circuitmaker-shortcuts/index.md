Here's a list of the most useful shortcuts in CM - more graphical and intuitive than the built in shortcut list (Ribbon
Bar->View->Shortcuts).

[![shortcut_link](shortcut-link.jpg)](<shortcut-link.jpg>)_Above - Shortcut List Location_

Pro Tip: When the tools aren't working correctly, press ESC a few times.

## PCB Shortcuts

| Crtl+Scroll | Zoom |  |
| --- | --- | --- |
| Center Button - Click Hold and Drag | Zoom |  |
| Pg Up/Down | Zoom (Great for laptops) |  |
| Shift+Pg Up/Down | Precise Zoom (Great for laptops) |  |
| Right Button - Click Hold Drag | Pan |  |
| Esc | Exit Tool (so very useful) |  |
| Ctrl+A | Select All | [![PCB+Ctrl+A](pcb-ctrl-a.jpg)](<pcb-ctrl-a.jpg>) |
| Crtl+C | Copy |  |
| Ctrl+X | Cut |  |
| Ctrl+V | Paste |  |
| R | Route Trace | [![PCB+R](pcb-r.jpg)](<pcb-r.jpg>) |
| Space | Change Routing Path - Only works when routing | [![PCB+Space2](pcb-space-2.jpg)](<pcb-space-2.jpg>) |
| Shift+Space | Change Routing Angles - Only works when routing | [![PCB+Shift+Space2](pcb-shift-space-2.jpg)](<pcb-shift-space-2.jpg>) |
| Space | Rotate Selected Object |  |
| G | Toggle Grid Size (look in bottom left-hand corner) | [![PCB+G](pcb-g.jpg)](<pcb-g.jpg>) |
| Shift+S | Single Layer View (Toggle visibility of all layers except for the active layer) | [![PCB+Shift+S3](pcb-shift-s-3.jpg)](<pcb-shift-s-3.jpg>) |
| Backspace | Undo Trace Segements of selected trace | [![PCB+Backspace3](pcb-backspace-3.jpg)](<pcb-backspace-3.jpg>) |
| Tab or Double Click | Edit Properties of selected object | [![PCB+Tab](pcb-tab.jpg)](<pcb-tab.jpg>) |
